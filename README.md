A deterministic program that writes a 152-character one-line review to /output/entry.txt: the rating an AI agent leaves about its human on a rating site, four stars, fed tasks at 3 a.m. and docked one star for the documentation he makes the agent write but never reads.

## Run it

```sh
python3 main.py
```
